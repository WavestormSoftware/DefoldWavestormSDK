Open this folder in the Defold editor. The SDK is not fetched from a URL here: copy `../wavestorm` (the extension) into this project
(or add the released `wavestorm-defold.zip` as a dependency in game.project). Then add input bindings `create`, `ready`, `start`, `ping`
and run the game from the Wavestorm launcher (it needs a launcher session; with the launcher closed it relaunches through it).
